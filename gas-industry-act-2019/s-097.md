# 97. Issue of codes
(1) Either of the following persons may issue codes for the purposes of this Act, including for the protection of small customers:
(a) the Minister;
(b) the Regulator.
(2) A code may provide for any matter relating or incidental to the supply or selling of gas by retail.
(3) A code must be consistent with this Act.
(4) A code must be in the public interest.
(5) If there is an inconsistency between a code and this Act, the code is invalid to the extent of the inconsistency.
(6) A code may be made so as to apply differently according to matters, limitations or restrictions, whether as to time, circumstance or otherwise, specified in the code.
(7) A code may authorise any matter to be from time to time determined, applied or regulated by –
(a) the Regulator; or
(b) the Tribunal; or
(c) a tribunal established under the code.
(8) If the Minister issues a code, the Minister must notify the Regulator and provide a copy of the code to the Regulator.
(9) If the Regulator issues a code, the Regulator must notify the Minister and provide a copy of the code to the Minister.
