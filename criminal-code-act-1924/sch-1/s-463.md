# 463. Application of Criminal Code Amendment (Bullying) Act 2019
(1) The amendments to this Act made by the Criminal Code Amendment (Bullying) Act 2019 do not apply in relation to an offence committed before the day on which the amendments commence.
(2) For the purposes of subsection (1), if an offence is alleged to have been committed between two dates, one before and one after the commencement of the Criminal Code Amendment (Bullying) Act 2019, the offence is alleged to have been committed before that commencement.
