# 319. Statements in proceedings for perjury
In an indictment for a crime which relates to giving false testimony, or procuring or attempting to procure the giving of false testimony, it is not necessary to allege the jurisdiction of the court or tribunal before which the false testimony was given, or intended or proposed to be given, or to set forth the proceedings or any part of the proceedings in the course of which the crime is alleged to have been committed.
