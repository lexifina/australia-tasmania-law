# 103. Type 3 fireworks to be stored only in packages in approved magazines
(1) A person must not store Type 3 fireworks anywhere other than in an approved magazine.
Fine not exceeding 50 penalty units.
(2) A person who stores Type 3 fireworks must ensure that all of those fireworks are in sealed unbroken packages and that each of those packages bears a label clearly and accurately identifying the kind of Type 3 fireworks that it contains.
Fine not exceeding 50 penalty units.
