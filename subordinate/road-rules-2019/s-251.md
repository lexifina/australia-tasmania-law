# 251. Riding to the left of oncoming bicycle riders or personal mobility device users on a path
The rider of a bicycle riding on a bicycle path, footpath, separated footpath or shared path must keep to the left of an oncoming bicycle rider and a person using a personal mobility device on the path.
Fine not exceeding 2 penalty units.
Bicycle path and separated footpath are defined in rule 239, footpath and personal mobility device are defined in the dictionary, and shared path is defined in rule 242.
