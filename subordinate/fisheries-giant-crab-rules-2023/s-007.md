# 7. Classes of fishing licence
For the purposes of these rules, a fishing licence is one of the following classes:
(a) class giant crab, fishing licence (giant crab);
(b) class rock lobster, fishing licence (rock lobster);
(c) class recreational, fishing licence (recreational rock lobster pot);
(d) class personal, fishing licence (personal);
(e) class vessel, fishing licence (vessel).
