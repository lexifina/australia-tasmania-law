# 130. Combined set lines
(1) A person must not combine one of their set lines with the set line of another person and set it in water of a depth less than 150 metres unless –
(a) the set line is combined with the set line of no more than one other person; and
(b) the other person is –
(i) the holder of a fishing licence (recreational set line); or
(ii) an Aborigine engaged in an Aboriginal activity; and
(c) the other person is present on the vessel when the combined set line is set and retrieved; and
(d) the total number of hooks on the combined set line is not more than 30.
Grade 2 penalty.
(2) A person must not combine one of their set lines with the set line of another person and set it in water of a depth of 150 metres or more unless –
(a) the set line is combined with the set line of no more than 3 other persons; and
(b) each of the other persons is –
(i) the holder of a fishing licence (recreational set line); or
(ii) an Aborigine engaged in an Aboriginal activity; and
(c) each of the other persons is present on the vessel when the combined set line is set and retrieved; and
(d) the total number of hooks on the combined set line is not more than 60.
Grade 2 penalty.
(3) A person who uses a combined set line must –
(a) comply with rule 127 or 128, whichever is relevant to the set line; and
(b) ensure that each person who combines his or her set line into the combined set line has also complied with rule 127 or 128, whichever is relevant to the set line.
Grade 2 penalty.
