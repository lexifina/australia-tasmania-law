# 65. Occupancy permit required
For the purpose of section 216(1)(f) of the Act, the following classes of building are prescribed for the purposes of that section:
(a) Class 1 buildings;
(b) Class 2 buildings;
(c) Class 3 buildings;
(d) Class 4 buildings;
(e) Class 5 buildings;
(f) Class 6 buildings;
(g) Class 7 buildings, other than a Class 7b building that was constructed as low-risk work and is a specified farm shed;
(h) Class 8 buildings;
(i) Class 9 buildings.
