# 52. Prescribed class of standard gas installation
The following classes of standard gas installations are prescribed for the purposes of section 54(3) of the Act:
(a) a gas installation for residential premises within a Class 2 or Class 4 building (within the meaning of the Building Code of Australia) exceeding 3 storeys;
(b) a gas installation in a building, excluding Class 1a buildings, with more than one meter where the meters are located in a common area.
