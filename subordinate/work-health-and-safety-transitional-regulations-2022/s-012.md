# 12. Tree lopping
(1) In this regulation –
approved code of practice
means a code of practice that has been approved under section 274 of the new Act;
crane-based tree lopping
means tree lopping using a method where a person is placed in a tree by a crane.
(2) Regulation 221 of the new regulations does not apply until an approved code of practice, detailing safety practices in relation to crane-based tree lopping, takes effect.
