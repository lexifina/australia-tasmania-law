# 722. Application to set aside registration
(1) Any application to set aside the registration of a judgment is to be made in the proceeding in which the judgment was registered.
(2) The application is to –
(a) set out the grounds of the application; and
(b) be supported by an affidavit verifying those grounds.
(3) The application and the affidavit in support are to be served on the person who obtained registration of the judgment.
