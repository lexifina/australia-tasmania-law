# 525. Making of interlocutory applications
(1) An interlocutory application is to be –
(a) in accordance with the prescribed form; and
(b) entitled in the proceeding in which it is made; and
(c) lodged at the registry with as many copies as the applicant requires.
(2) If the application is in order for filing, the person receiving it is to file it, seal the copies and return them to the person lodging the application.
