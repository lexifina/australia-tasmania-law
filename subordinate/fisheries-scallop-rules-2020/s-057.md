# 57. Scallop processor returns
(1) In this rule –
return arrangements
means requirements relating to the completion of, and provision to the Secretary of, an approved scallop processor return;
scallop processor return
means a return relating to processed scallops that is part of the records required to be kept under the Act.
(2) Subject to subrule (3), the holder of a fish processing licence must, within 7 days after the end of the month in which any scallops have been processed under that licence –
(a) complete an approved scallop processor return; and
(b) provide that return to the Secretary.
Grade 1 penalty.
(3) If the Secretary notifies the holder of a fish processing licence in writing that he or she is to comply with alternative return arrangements under this rule, the holder of the fish processing licence must comply with those alternative return arrangements instead of subrule (2).
Grade 1 penalty.
