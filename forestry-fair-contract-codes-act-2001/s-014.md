# 14. Publication of Codes
(1) The Minister may cause a Code to be published from time to time as the Minister sees fit.
(2) The Minister must cause to be made available in the principal office of the Department, for inspection by members of the public free of charge during normal office hours –
(a) each Code that is in force; and
(b) if a Code incorporates another document, that other document.
(3) The Minister may cause copies of a Code to be made available for purchase.
(4) A copy of a Code published or made available for inspection or purchase under this section is to be inclusive of any approved variations of the Code that are in force when it is published or made available.
