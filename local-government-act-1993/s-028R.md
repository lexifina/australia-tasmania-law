# 28R. Model code of conduct
(1) The Minister, by order, is to make a model code of conduct relating to the conduct of councillors.
(2) The Minister, by order, may amend or revoke and substitute the model code of conduct.
(3) The Minister is to make a copy of the model code of conduct available to each council as soon as practicable after the model code of conduct is made, amended or revoked and substituted.
