# 43. Values determined under this Act to be values for purposes of other Acts
A reference in an Act –
(a) to the land value of any land is to be construed as a reference to the land value of that land as shown in the valuation roll for the valuation district in which it lies; and
(b) to the capital value of any land is to be construed as a reference to the capital value of that land as so shown; and
(c) to the annual value or assessed annual value of any land is to be construed as a reference to the assessed annual value of that land as so shown.
