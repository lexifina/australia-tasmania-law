# 93. Notifiable building work
(1) For the purposes of this Act, the Director of Building Control may determine that specified building work, or a specified class of building work, is notifiable building work.
(2) Despite subsection (1), building work is not notifiable building work if any part of the building work is –
(a) emergency work; or
(b) building work that is performed as part of work performed under an emergency order or a building order.
